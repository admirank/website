# AdmiRank Landing Page

A responsive static landing page built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and demo interactions
- `assets/` — supplied AdmiRank logo and DU batch artwork

## Preview locally
Open `index.html` in a browser. For development, you can also use VS Code Live Server.

## Deploy to Vercel
1. Create a GitHub repository, for example `admirank-website`.
2. Upload the complete project, keeping the `assets` folder.
3. In Vercel, import the repository.
4. Choose the framework preset `Other`; leave build command and output directory empty/default.
5. Deploy.

This is the landing-page frontend only. Login, enrollment, payment, student dashboard and exam features are not connected yet.
