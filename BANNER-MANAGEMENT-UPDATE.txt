AdmiRank banner management update

- Admin > Website content > Banners now has a dedicated banner manager.
- Admins can upload PNG/JPG/WebP banners, hide/show them, and permanently delete uploaded banners.
- Existing project assets assets/du-a-banner.png and assets/du-b-banner.png are displayed by default and can be hidden/shown from the admin manager.
- Homepage banners are sorted by display_order and stacked with no gaps. Images keep their natural aspect ratio.
- Uploaded images use the existing Supabase Storage bucket: public-assets.
- Run supabase-migration-v6-banner-management.sql in Supabase SQL Editor after v4 to ensure public read and admin-only upload/delete permissions for banners and public-assets.
- No new database tables or columns are required; existing banners columns are reused.
